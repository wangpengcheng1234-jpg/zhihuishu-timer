# 智慧树每日学习计时器

一个 Chrome / Edge 浏览器扩展，帮你统计智慧树（zhihuishu.com）每日视频学习时长，避免无效挂机。

## 功能

- **精准计时**：只在视频实际播放时计时（切后台标签页也计入），暂停/弹题时不计
- **课程库自动同步**：每次进入智慧树课程列表页自动刷新课程库，发现新课程时通知你设置是否参与每日学习
- **按课程开关**：扩展弹窗中可勾选哪些课程需要每日学习，未勾选的课程不计时、不提醒
- **达标自动暂停**：达到每日目标（默认 26 分钟，可自定义）后自动暂停视频，顶部横幅提示（不遮挡页面），语音播报（仅 macOS）；点击「继续学习」可解除当日锁定
- **弹题系统通知**：视频弹出题目时发送系统通知，点击通知可跳回学习页面
- **忘点播放提醒**：题目关闭 10 秒后视频仍未播放时，系统通知提醒回去点播放
- **播完提醒**：当前视频播完但未达目标时，系统通知提醒手动跳转下一节
- **每日进度提醒**：每天首次打开浏览器时通知今日学习进度；0 点自动清零重新计时
- **进度可视化**：扩展弹窗实时显示今日已学时长与进度条

## 支持平台

| 平台 | Chrome | Edge |
|------|--------|------|
| Windows | ✅ | ✅ |
| macOS | ✅ | ✅ |

> 语音播报功能依赖 macOS「快捷指令」App，仅 macOS 可用；其余功能全平台通用。

## 安装

1. 下载本仓库源码（或 Release 里的 zip 并解压）
2. 打开 `chrome://extensions/`（Chrome）或 `edge://extensions/`（Edge）
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择 `zhihuishu-timer` 文件夹

## 使用

1. 登录智慧树，打开任意课程的视频学习页面，正常播放视频即可自动计时
2. 点击工具栏扩展图标查看今日进度、修改每日目标时长
3. 弹题通知开关可在弹窗中关闭

### 语音播报设置（仅 macOS）

1. 打开 macOS「快捷指令」App，新建快捷指令，添加「朗读文本」动作，命名为「智慧树提醒」（或任意名称）
2. 在扩展弹窗的语音播报输入框中填入该快捷指令名称；留空则停用语音提醒
3. 首次触发时勾选「始终允许」，之后免确认

## 权限说明

| 权限 | 用途 |
|------|------|
| `storage` | 保存每日计时、目标时长、通知开关等设置 |
| `notifications` | 弹题提醒、播完提醒、每日进度提醒 |
| `tabs` | 点击通知时定位并激活学习页面 |
| `scripting` | 在智慧树页面注入脚本（备用） |
| `host_permissions: *.zhihuishu.com` | 仅在智慧树域名下运行计时脚本 |

## 技术说明

- Manifest V3，无构建步骤，纯原生 JS
- Content Script 运行在隔离世界，不修改页面任何原生函数，不向 `window` 写入属性
- 后台 Service Worker 负责计时累计、跨天重置与通知分发
